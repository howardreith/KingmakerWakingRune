## Proposed guarded transaction

1. **Prepare offline.** Resolve the three missing rows, loader, load order, config and auxiliary files. Record and review one complete per-file staging manifest and an outside-Mods write list. Reject absolute paths, parent traversals, case collisions, unlisted files and reparse points in inputs. Do a full stage, simulated failure after each write group, restart recovery and byte-for-byte rollback against a disposable filesystem tree. Store only inventories and diagnostics in review artifacts.
2. **Extend the guard before requesting the second authorization.** The current `KwrRuntime.ps1 Begin` backs up the installed Waking Rune folder and inventories all Mods. Its `End` restores Waking Rune and detects differences in other Mods. It cannot restore a replaced loader, a foreign mod tree or a soundbank. Add a journaled compatibility operation to the guard with one owner per path as listed below. A bare `Begin` followed by manual copies is insufficient. Both the approved wrapper revision and the staging-manifest SHA-256 belong in the second request.
3. **Snapshot before the first write.** With Steam Cloud proven disabled, no game running, no active transaction and owner-confirmed inputs, mint a new run ID (proposed `wrplay3-0123-profile`). Resolve all destinations under their declared roots. Journal the original bytes, attributes, presence or absence and per-file hashes for every managed path. The guard must be able to resume rollback after a process or machine restart. Retain the original content until verification succeeds.
4. **Stage and verify.** Begin the guarded candidate transaction, then stage only the 27 companion mods, logged configuration and approved loader overlay from the sealed manifest. Verify the final 28 IDs and versions, all DLL, asset and config hashes, loader version, effective enabled state and load order. Launch first to a disposable main-menu/stock fixture. Compare the load log and generated-cache identities with the baseline. Mismatches block owner-save copies and the Frost Giant/Extend case. Use named disposable saves only after that second authorization and profile verification. The original owner saves remain outside the test workspace.
5. **Collect, restore and prove parity.** Collect the native log and video before closing or restarting. Gracefully close only the owned process. In the recovery path restore the compatibility operation's paths first, then run `KwrRuntime.ps1 End` without `-KeepInstalled`. Compare every protected tree in both directions against the pre-run snapshot, including pristine file hashes and the recorded absence of run-created files. Verify loader and UMM settings, all Mods, the 0.11.3 DLL/cache, profile/saves, Steam remote mirror and exported registry. Record discrepancies and keep the snapshot and journal open until corrected. Retain only the run's evidence and quarantined additions under the lab.
